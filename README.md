# 升级 Yii3（202608）

结果真的更新了yii3。。。那就来还债吧。

从Yii2到Yii3基本等于重写了一遍，配置/容器/路由/视图渲染全换了，但业务逻辑和数据库结构尽量保持一致，迁移成本可控。

> 因为最近几年都没写 PHP，上次升级 Yii2 花了两天，这次如果古法手搓 Yii3 + React，我估计得花一个月。还好赶上`DeepSeek-V4-Flash-0731`正式版更新，花了三天时间跑了 22 亿 token 就完成了升级，消费DeepSeek 共50块，免费蹬了OpenCode有两亿的免费token（mimo-2.5+flash-0731）。
>
> 除了这段描述，README.md 文档也是 mimo 仿照之前的风格写的。

### 做了什么

+ 后台SPA（React+AntD），文章/分类/评论/标签/导航/用户/评论配置全打通
+ 三套主题：默认、Crazydb（Yii2同款）、墨刊（杂志风格），后台可切换
+ Redis缓存、Session、浏览量异步合并、配置版本化key
+ 文章密码保护（md5哈希）、登录限流（Redis 5次/15分钟）
+ 前台UI重做：登录注册表单、Flash浮层通知、注册开关、面包屑
+ 作者链接体系统一（笔名快照>用户昵称）、About Me从数据库读取
+ 评论表单精简（去掉了网址字段）
+ 单元测试 phpunit 全绿
+ 墨刊（杂志风格）是由 mimo 设计并实现

### 没做什么

RBAC还是没加，日志还是不全，插件/模块系统继续拖延。

### 部署

docker-compose一把梭：nginx + php + mysql + redis，`./yii init/env` 填配置，`./yii init/admin` 建管理员，完事。
